Aponte a câmera do seu celular para o QR Code abaixo para abrir esta experiência e posicionar o produto no seu ambiente real.

Como usar a Realidade Aumentada

  1. 1. Escaneie: Aponta a câmera do celular para o QR Code no topo da página.
  2. 2. Aguarde: Espere o modelo 3D carregar na tela do seu celular.
  3. 3. Toque no Botão: Pressione o botão verde “Visualizar no meu ambiente”.
  4. 4. Posicione: Mova o celular apontando para o chão ou mesa para colocar o produto na sua sala.
